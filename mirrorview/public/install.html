Como instalar • 3 passos

Leva menos de um minuto. Nenhuma configuração é necessária.

1

Copie a URL do manifesto na caixa MirrorView abaixo.

2

No Stremio, abra Addons → 🔗 Link simbólico (Install via addon link).

3

Cole a URL, clique em Instalar e aproveite. Pronto!

Procurando filmes e séries? Eles são do addon MirrorStream — a TV é deste produto aqui. Se usa Nuvio, instale os dois: o MirrorView traz a lista de canais, o MirrorStream o catálogo de VOD.
