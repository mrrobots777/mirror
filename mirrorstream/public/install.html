Como instalar • 3 passos

Você precisa do addon sempre. O plugin só se você usa o Nuvio.

1

Copie a URL do addon na caixa MirrorStream abaixo.

2

No Stremio, abra Addons → 🔗 Link simbólico (Install via addon link).

3

Cole a URL, clique em Instalar e aproveite. Pronto!

Usa Nuvio? Depois de instalar o addon, adicione o repositório de plugin em Ajustes → Plugins → Adicionar URL de repositório, usando a URL do plugin abaixo. O Nuvio não tem lista de canais própria — ela vem do addon MirrorView.

Os dois manifestos • addon e plugin

Não são o mesmo arquivo. O addon é um manifesto de addon; o do plugin é um manifesto de plugin, servido pelo GitHub Pages.
